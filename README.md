# Мяу-Ниндзя: Стальной город

Браузерная игра-платформер со стелсом. Котёнок Тень — последний ниндзя-кот — защищает город от армии роботов злого доктора Болта.

**Как запустить:** открой `index.html` в любом браузере (ничего устанавливать не нужно). Работает и на телефоне — появятся кнопки на экране.

## Что есть в игре
- 🏙️ Крыши, лазание по стенам, тени — в тени роботы тебя не видят, а если красться (↓), замечают только вблизи.
- ⭐ Клубки-сюрикены, дымовые бомбы и супер-мурчание, которое оглушает роботов. Атака со спины или по оглушённому роботу — урон ×2.
- 🤖 Из деталей 🔩 побеждённых роботов собирается робот-помощник Болтик (5 деталей), а потом улучшается (ещё 8).
- 🎮 5 уровней от лёгкого к сложному, подсказки по ходу игры, финальный бой с доктором Болтом. Прогресс сохраняется.

## Управление
| Действие | Клавиши |
|---|---|
| Бег | ← → / A D |
| Прыжок | ↑ / W / Пробел |
| Красться | ↓ / S |
| Лазать по стене | прыгни к стене и держи стрелку к ней, ↑ — вверх, ↓ — вниз |
| Клубок | J / Z |
| Дымовая бомба | K / X |
| Супер-мурчание | L / C |
| Собрать / улучшить помощника | B |
| Пауза / заново / звук | P / R / M |
